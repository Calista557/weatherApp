Aura Weather is a responsive weather application built with HTML, CSS, and JavaScript. The application allows users to search for a city and view real-time weather information using the OpenWeather API.

This project was created to practice frontend development skills, including working with APIs, handling asynchronous JavaScript, processing JSON data, and updating the webpage dynamically based on user input.

The application features a clean and user-friendly design that works across desktop and mobile devices. Users can search for different locations and view important weather details such as temperature and weather conditions.

Building Aura Weather provided hands-on experience with API integration, JavaScript fetch requests, DOM manipulation, and creating interactive web applications.
